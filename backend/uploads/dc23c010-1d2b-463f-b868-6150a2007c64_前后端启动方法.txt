前后端启动方法

  启动后端 (Backend)

  cd "C:\Users\13813\my-wiki\backend"
  python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

  如果遇到端口占用，先关闭旧进程：
  taskkill /F /PID $(lsof -ti:8000 2>/dev/null) 2>/dev/null || netstat -ano | findstr :8000

  启动前端 (Frontend)

  cd "C:\Users\13813\my-wiki\frontend"
  npm run dev

  前端默认运行在 http://localhost:5173，后端在 http://localhost:8000。

  注意事项

  - 后端依赖 .env 文件中的 API 密钥配置
  - 确保已安装后端依赖：pip install -r requirements.txt
  - 确保已安装前端依赖：npm install
  - 后端启动时会自动创建数据库和种子数据
